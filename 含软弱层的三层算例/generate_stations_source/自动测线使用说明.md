# 自动选择唯一公共交点的测线

修改 `generate_sources_stations.py` 顶部用户编辑区，然后用 Python 3.10 运行。默认结果仍写入本目录的 `output`。当前用户设置保留为上层 P、50°、110 Hz；60°、95 Hz 的示例单独放在 `preview_upper_P_60_95Hz_auto`。

## 主要开关

| RECEIVERS 参数 | 当前值 | 含义 |
|---|---:|---|
| auto_reflection_line | True | 启用自动选线；False 恢复指定的共同交点 |
| auto_common_intersection | True | 联合选择唯一公共交点；所有测线延长线共点，入射测线只有一条 |
| auto_ray_distance_max_m | 1000 | 自动模式允许搜索的最大沿线距离，仍裁在研究小盒内 |
| min_clean_line_length_m | 100 | 优先达到的连续长度 |
| allow_short_clean_lines | True | 用户允许保持源面，无法同时达到100m时接受较短合格段 |
| min_short_clean_line_length_m | 20 | 短段硬下限，不能用混波站凑长度 |
| ray_step_m | 5 | 沿测线的台站间距 |
| incident_min_source_distance_m | 100 | 入射站位于源面前方，离源面至少此距离 |
| source_foot_edge_clearance_m | 50 | 对应入射射线在源线上的垂足离源线两端的最小距离 |
| isolation_half_periods | 2 | 假设单个波包半宽为 2/f 秒 |
| isolation_guard_s | 0.005 | 两个波包之间另留 5 ms |

旧参数 `ray_distance_max_m=300` 只约束固定交点/旧自动模式；新自动模式使用 `auto_ray_distance_max_m`。自动模式不把不满足条件的站补回测线。只有明确开启短段开关时才允许缩短，源面位置保持不动。

## 为什么搜索公共交点而不是固定中间点

在均匀上层 P 波入射、反射 P 波的几何近似下，同一位置的两相位时间差为

`Δt = 2 × 到界面的竖直距离 × cos(入射角) / Vp`。

在入射或反射 P 测线上，若沿线距离为 d，则 `Δt = 2d cos²θ / Vp`。因此仅平移共同界面交点，不改变这个时间差；大角度时仍需要离界面更远的站。程序联合比较同一个交点对应的全部测线，选择最短可用测线尽可能长的位置，不再各线单独选点。

## 筛选过程

1. 从实际有限源线计算入射波束范围，在研究区域内扫描界面交点；检查该交点能被源面照射，且射线垂足避开源线两端。
2. 对每条候选测线逐站检查研究区域边界、介质、源面位置和台站间距。
3. 入射站也检查与反射 P/SV 的时间差。反射站检查与初始入射波及另一反射波的时间差。是否存在竞争的几何反射射线，由反向追踪到界面、再检查有限源照射范围判断。竞争波束边缘按 `incident_beam_clearance_m` 向外加保护带，不能刚越过边缘就认为无竞争波。
4. 时间隔离要求 `Δt ≥ 2 × isolation_half_periods / f + isolation_guard_s`。`space` 模式还要求反射站位于入射波束外；找不到时不会自动改用时间模式。
5. 对每个公共交点，分别找各线的连续合格段；联合评分首先最大化其中最短段的长度，再比较总长度、时间差及边缘距离。只有一条入射线。不存在共同可行交点时不退回多个交点。

公共点位于入射侧的软弱层界面。透射线在另一界面有约一个层厚的几何起点偏移，确保向后延长仍穿过同一个公共点。这些线是相位采样线，不代表软弱层中多次转换波的唯一真实路径。到界面的距离仍从各台站所在侧界面量起。

透射线目前检查传播条件、照射范围和几何连续性，不宣称已分离透射 P/SV 的混波或软弱层多次波。有限源边缘绕射、背向波、薄层群延迟和三维散射仍须用实际记录复核；上述几何筛选不是全波场无干扰证明。

## 60°、95 Hz 示例

| 测线 | 界面交点全局 X / m | 沿线距界面范围 / m | 台站数 |
|---|---:|---:|---:|
| I_P | 2186 | 255–285 | 7 |
| R_P | 2186 | 310–350 | 9 |
| R_SV | 2186 | 180–570 | 79 |
| T_SV | 2186.762252（远侧界面） | 20–500 | 97 |

所有延长线通过同一个点：**全局X=2186m、Y=300m、埋深=1999m**。最短段30m。初步不加竞争波束边缘保护带时可得到40m；最终加入10m保护带后采用30m，不以靠近波束边缘的站凑长度。

所有站仍在全局 Y=300 m 平面、研究小盒内，坐标文件使用埋深。该角度的下层透射 P 为倏逝分支，不生成传播测线。

`stations_three_layers.png` 显示源面、入射波峰线、唯一公共交点与测线；`line_separation_check.png` 显示入射/反射站的竞争相位时间差。逐站检查值写入 `automatic_line_separation_audit.csv`，选择结果写入 `geometry_report.json`。

## 后处理兼容与重新计算

`config_used.json` 记录 `receivers.common_intersection_x_depth_m` 以及各线在自身界面的实际起点 `interface_hit_x_by_phase_m`。后处理据此计算距离；旧 prepare 缺少该字段时仍按旧共同交点解释。

当 prepare 明确记录 `short_clean_lines_accepted=True` 时，后处理默认把自动选段长度降至共同可用长度（此示例30m），并在XLSX说明原请求100m、实际30m。可通过后处理顶部 `ALLOW_PREPARED_SHORT_SEGMENTS=False` 关闭。新布局入射/反射拾取窗默认读取布站时的波包半宽，防止后处理用更宽的窗重新混入已避开的震相。

直接法仍为直接峰÷入射直接峰，包络法仍为包络峰÷入射包络峰。

新布站与旧布站的位置不同，台站编号也会重新生成。必须使用新 STATIONS 重新模拟，并将同次生成的完整输出放入该算例 prepare。不能把新 prepare 配给旧台站波形，否则相同编号可能代表不同位置。既有算例的 prepare、sema、mesh 不会被此脚本自动改写。
